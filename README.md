# 运营开号与素材收集界面

这是开号信息收集和生产素材收集的界面，以及对应的四步运营流程说明。本仓库只放这套收集界面，不包含房源视频 MCP 或其他服务代码。

## 四步流程

1. **开号收集**：只用第一界面收集基础信息，写入用户资料库。界面不生成运营方案。
2. **对话出方案**：回到自然对话，由助手生成可审阅的运营方案文档。用户接受或修改，直到确认。目标市场和目标人群的初步判断放在方案里；信息不足时标「待验证」，可编辑，不在开号时锁定。
3. **确认后开始生产**：方案确认后，助手主动询问是否开始生产，检索来源并推荐选题。用户先选定第一支或若干选题；用户指定的内容优先。
4. **收集展示素材并交付**：生产方向确定后，如需展示素材，回到对应的收集界面。收集完成后，在对话中制作并交付。

## 文件

| 文件 | 说明 |
| --- | --- |
| `ops-intake.html` | 第一界面：用户基础信息、想做什么，以及对外展示信息 |
| `ops-materials.html` | 素材收集：房源展示（以房源 URL 为主） |
| `ops-story.html` | 素材收集：成交故事（案例简述、链接、不限形式文件含 PDF/Word、补充信息） |
| `ops-bio.html` | 素材收集：个人或团队介绍（链接、不限形式文件含 PDF/Word、介绍文字、补充信息） |
| `screenshots/` | 界面关键状态截图，便于对照 |

用浏览器直接打开这些 HTML 文件即可使用。

开号页和素材页通过 `localStorage` 共享键 `ops-user-library` 和 `ops-display-profile`。注意：以 `file://` 分别打开时，浏览器可能不会共享存储。

完成收集后，结果会自动复制为纯文本，方便粘贴回对话。助手不会自动探测或拉取表单结果。若上传了文件，请把原文件和复制结果一起发回对话。预览参数（`?preview=...`）只用于截图，不会触发自动复制。

## 第一界面（开号收集）

- 主要收集基础信息和「想做什么」，必填项尽量少，更细的偏好为选填。
- 按钮文案是「完成收集」，不要写成「重新生成运营方案」。
- **对外展示信息**（始终可见）：姓名必填；头衔、电话、邮箱、头像选填。
- 这些信息只用于对外展示，不是登录凭证。后续制作房源视频时可自动同步。
- 用户可在单条内容上改展示项，但不会改这里保存的开号资料。

## 素材收集：房源展示

- 以房源 URL 为先。
- 可选择「是否展示经纪人个人信息」。
- 若选择展示：按字段勾选，并可只为这一条填写覆盖值（标记「本次更换」），不改开号资料库。
- 默认勾选：已有值的「姓名」和「电话」；「头衔」「邮箱」「头像」默认不勾。
- 至少勾选一个已有值的字段，才能完成收集。

## 素材收集：成交故事

- 可选填写标准案例表单：这笔是（帮客户买入 / 帮业主卖出 / 其他）、区域或社区、成交时间或周期、成交价格或区间、案例简述。
- 支持上传相关链接，以及不限形式的文件（图片、音频、视频、PDF、Word 等文档均可）。
- 可填写补充信息（例如要求匿名、不要露出客户正脸）。
- 至少提供一项材料（简述、链接或任意文件），或选择暂时跳过。
- 收集结果用于后续制作叙事型内容；界面本身不生成文案。

## 素材收集：个人或团队介绍

- 必选介绍对象：个人或团队。
- 支持上传相关链接，以及不限形式的文件（图片、音频、视频、PDF、Word 等文档均可），并填写介绍文字。
- 可填写补充信息。若开号资料里已有对外姓名或头衔，页面会提示，但不会改开号资料。
- 至少提供一项材料（链接、任意文件或介绍文字），或选择暂时跳过。
- 收集结果用于后续撰写专业 Bio 文案；界面本身不生成文案。
